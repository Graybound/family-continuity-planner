## Before every release

- [ ] `npm run check` passes
- [ ] `npm run privacy-scan` with your local `.privacy-denylist`
- [ ] CHANGELOG updated, version bumped
- [ ] Release draft reviewed: zip extracted and opened from disk, checksums verified
- [ ] Any new data format change has a migration, fixture, tests, and docs

## Publication gate

Do not make the repository public or publish a release until every TODO above is resolved or consciously accepted.
